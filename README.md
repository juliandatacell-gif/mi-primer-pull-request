# Mi Primer Pull Request

Este es un repositorio de practica para aprender a usar Git y GitHub.

## Sobre este proyecto

Este repositorio fue creado para aprender el flujo de trabajo de un Pull Request:
crear una rama, hacer un cambio, y proponerlo para que sea revisado y aceptado.

## Objetivo

Aprender a colaborar en proyectos de codigo de forma ordenada, tal como lo hacen
los programdores en el mundo real.
